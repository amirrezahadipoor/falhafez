# حمایت مالی و حذف تبلیغات (Poolakey / کافه‌بازار)

## شناسهٔ محصولات (SKU) برای ثبت در پنل بازار
در پنل توسعه‌دهندگان کافه‌بازار → برنامهٔ شما → «پرداخت درون‌برنامه‌ای»، این سه **محصول غیرمصرفی** را بساز:

| SKU | نام | قیمت |
|---|---|---|
| `fal_support_base` | حمایتِ پایه | ۱۰۰٬۰۰۰ تومان |
| `fal_support_plus` | حمایتِ ویژه | ۳۰۰٬۰۰۰ تومان |
| `fal_support_gold` | حمایتِ همیشگی | ۴۹۰٬۰۰۰ تومان |

سپس **کلید عمومی (RSA)** همان بخش را کپی کن و در
`data/payments/BazaarKeys.kt` → `RSA_PUBLIC_KEY` بگذار.

## وضعیت فعلی
- **Poolakey 2.0.0** (`com.github.cafebazaar.Poolakey:poolakey`) وصل شده.
- `BazaarPaymentGateway` جریان کامل خرید (connect → purchase → grant) را پیاده می‌کند.
- DEBUG: خرید آزمایشی فوراً ثبت می‌شود. RELEASE بدون کلید RSA: صفحهٔ بازار باز می‌شود (بدون خطا).

## سطح‌های حمایت (همه تبلیغات را برای همیشه حذف می‌کنند)
| سطح | قیمت | امکانات |
|---|---|---|
| حمایتِ پایه | ۱۰۰٬۰۰۰ تومان | حذف کامل تبلیغات |
| حمایتِ ویژه | ۳۰۰٬۰۰۰ تومان | حذف تبلیغات + قالب «شبِ یلدا» + ۵ فال اضافه در روز |
| حمایتِ همیشگی | ۴۹۰٬۰۰۰ تومان | حذف تبلیغات + یلدا + فال بدون ضرب‌آهنگ + ۲۰ فال اضافه + نشان «پشتیبان» روی تصویر اشتراک |

## معماری
- `domain/model/Support.kt` → `SupportTier` (سه سطح + NONE)
- `data/payments/PaymentGateway.kt` → واسط پرداخت
- `data/payments/BazaarPaymentGateway.kt` → پیاده‌سازی
- `SupportRepository` → ذخیرهٔ سطح در DataStore (پایدار)
- لایهٔ تبلیغات (`TapsellAdManager`) و `HomeViewModel` وقتی `adsRemoved` باشد، هرگز تبلیغ نشان نمی‌دهند.

## وضعیت فعلی پرداخت
- **DEBUG**: خرید برای تست فوراً ثبت می‌شود.
- **RELEASE**: تا اتصال پرداخت درون‌برنامه‌ای کافه‌بازار، دکمهٔ خرید صفحهٔ بازارِ اپ را باز می‌کند.

## اتصال پرداخت واقعی کافه‌بازار (Bazaar IAP)
1. در پنل کافه‌بازار، برای اپ ثبت‌نام کن و «محصول درون‌برنامه‌ای» با سه SKU بساز:
   - `support_base` (۱۰۰٬۰۰۰ تومان)
   - `support_plus` (۳۰۰٬۰۰۰ تومان)
   - `support_gold` (۴۹۰٬۰۰۰ تومان)
2. SDK پرداخت بازار را به `app/build.gradle.kts` اضافه کن:
   ```kotlin
   implementation("com.farsitel.bazaar:bazaar:2.5.0")  // نسخهٔ جاری را چک کن
   ```
3. در `BazaarPaymentGateway.purchase` از `PaymentFlow` بازار استفاده کن و پس از موفقیت، `onPurchased()` را صدا بزن.
4. کلید RSA عمومی بازار را طبق مستندات رسمی پیکربندی کن.
> مستندات رسمی: https://developers.cafebazaar.ir
