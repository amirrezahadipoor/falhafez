# تحلیل وضعیت — چه کامل است و چه کم داریم (تاریخ: مرداد ۱۴۰۵)

## ✅ کامل و آماده
| بخش | وضعیت |
|---|---|
| محتوا | **۸٬۳۶۸ شعر** — حافظ ۴۹۵ کامل، خیام ۱۷۸ کامل، سعدی ۱٬۳۵۵ کامل، مولانا ۶٬۲۴۰ کامل + ۱۰۰ داستان آموزنده |
| فال | انتخاب منبع (حافظ/سعدی/مولانا/خیام/همه) + فالِ روز قطعی + ۲ فال رایگان روزانه + ویدیو برای فال بیشتر |
| تجربه | نیّت → انیمیشن گشودن دیوان → رونمایی بیت‌به‌بیت → تفسیر؛ صداها و هاپتیک |
| ظاهر | ۱۳ قالب (تیره و روشن)، چرخ‌دندهٔ چرخان، قلب تپندهٔ حمایت، اسکرول‌بار طلایی |
| امکانات | تاریخچه + کارنامه، علاقه‌مندی‌ها، دیوان با جستجوی FTS + معنی بیت (حافظ/سعدی/خیام)، حالت مطالعه، ویجت، یادآور روزانه، اشتراک تصویری به ۷ شبکه + کانال کاربر |
| تنظیمات | قالب، اندازه/رنگ قلم، صدا، لرزش، حمایت مالی، کانال من، برنامه‌های دیگر، بروزرسانی، پشتیبان‌گیری |
| درآمد | تپسل (۴ قالب با zone واقعی) + حمایت مالی ۳ سطحی (Poolakey) + حذف تبلیغات + فال نامحدود |
| انتشار | CI فقط-release، APK امضاشده با keystore واقعی، آیکون، اسکرین‌شات، حریم خصوصی، چک‌لیست |

## ⚠️ کمبودها (به ترتیب اهمیت)

### بلوکر برای انتشار (به دست تو)
1. **کلید عمومی RSA کافه‌بازار** — بدون آن، خرید اشتراک در نسخهٔ release کار نمی‌کند
   (`data/payments/BazaarKeys.kt`). از پنل بازار → «پرداخت درون‌برنامه‌ای» بگیر و بفرست.
2. **ثبت SKUها در پنل بازار** — سه محصول `fal_support_base/plus/gold` باید در پنل ساخته شوند.
3. **تأیید اپ در پنل تپسل** — تا وقتی اپ در app.tapsell.ir تأیید نشود، تبلیغ واقعی نمی‌آید.

### کیفی (پیشنهاد قبل از انتشار)
4. **تست روی دستگاه واقعی ایرانی** — بیلد و امولاتور سبز است ولی سرعت seeding (۸٬۳۶۸ شعر / ~۷۵ هزار بیت)
   روی گوشی ارزان (اندروید ۶–۷) هنوز اندازه‌گیری نشده.
5. **معنی بیت برای مولانا** — برای کم‌کردن حجم حذف شد (حافظ و سعدی و خیام دارند). در صورت نیاز اضافه می‌شود (+ حجم).
6. **تفسیرهای عمیق دست‌نویس** — فقط غزل‌های مشهور حافظ دست‌نویس‌اند؛ بقیه تولیدیِ متنوع (منسجم و آگاه به شاعر) هستند.
7. **onboarding** — هنوز یک صفحه است (پرامپت ۲–۳ صفحه می‌خواست).

### آینده (ارزش بالا)
8. **بازیابی (import) پشتیبان** — فعلاً فقط export است.
9. **راوی/صوتِ شعر** — عمداً حذف شد (ریسک کیفیت).
10. **تست واحد/UI** — فقط CI build + اعتبارسنجی کورپوس.
11. **انتشار اولیه + بازخورد واقعی کاربران** — مهم‌ترین قدم بعدی.

## نتیجه‌گیری
اپ از نظر «محصول» کامل است: محتوا، تجربه، درآمد و ابزار انتشار سر جاست.
سه بلوکر انتشار (RSA + SKU + تأیید تپسل) کاملاً دستِ توست و با یک پیام از تو فعال می‌شوند.
